# Сайт истории города Донецка (Вариант 1)

Учебный проект по курсу веб-программирования.  
**Лабораторная работа №1**: «Изучение HTML-тегов и CSS-стилей».

---

## 📌 О проекте
Многостраничный информационный веб-сайт, посвященный истории, инфраструктуре и культурному наследию города Донецка («Города миллиона роз»).  
Сайт полностью адаптивен, свёрстан с соблюдением семантики стандарта HTML5, без использования сторонних CSS/JS-библиотек и конструкторов.

---

## 🛠 Стек технологий
- **HTML5**: семантическая разметка (более 55 тегов, включая семантику HTML5: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, `<figcaption>`, `<time>`, `<meter>`, `<details>`, `<summary>`, `<progress>`, списки `<dl>`, `<dt>`, `<dd>` и др.).
- **CSS3 / SCSS**:
    - Централизованные переменные (`$primary-color`, `$secondary-color` и др.);
    - Миксины (`@mixin flex-box`, `@mixin card-box`);
    - Наследование (`@extend .btn-base`);
    - Древовидная вложенность стилей;
    - 4 типа позиционирования элементов (`static`, `relative`, `fixed`, `sticky`);
    - Обтекание текстом (`float`, `clear`);
    - Псевдоклассы (`:hover`, `:active`, `:focus`, `:valid`, `:invalid`, `:nth-child` и др.) и псевдоэлементы (`::before`);
    - Адаптивные сетки (CSS Grid, Flexbox).
- **Валидация**: проверка форм средствами HTML5 и регулярных выражений (`pattern`).

---

## 📄 Структура страниц
1. `index.html` — главная страница: описание города, адаптивная галерея достопримечательностей, лента актуальных событий.
2. `about.html` — страница автора проекта с горизонтальной столбчатой диаграммой профессиональных навыков.
3. `history.html` — хронологическая таблица 10 важнейших исторических событий города.
4. `infrastructure.html` — интерактивная карта, 9 административных районов и система городского транспорта со шкалой `<meter>`.
5. `culture.html` — театры, музеи и выдающиеся деятели Донбасса (список определений `<dl>`).
6. `contact.html` — форма обратной связи с интерактивной подсветкой валидации.
7. `emmet.txt` — комбинированные Emmet-инструкции для каждой страницы.
